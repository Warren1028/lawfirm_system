## 🎨 Customization

### Change Company Name
Edit `index.html`, find & replace:
- `LegalIntake Pro` → Your company name
- Update in navbar, footer, etc.

### Change Contact Info
Edit footer section:
```html
<a href="#">sales@yourcompany.com</a>
<a href="#">support@yourcompany.com</a>
<a href="#">+1 (555) 123-4567</a>
```

### Change Colors (Optional)
Edit `:root` in `style.css`:
```css
--primary-color: #E8F4F8;      /* Light background */
--secondary-color: #B3E0E8;    /* Medium blue */
--accent-color: #7ECFE0;       /* Bright blue */
```

**Alternative Soft Palettes:**
- Soft Green: `#E8F5E9`, `#C8E6C9`, `#81C784`
- Soft Purple: `#F3E5F5`, `#E1BEE7`, `#CE93D8`
- Soft Orange: `#FFF3E0`, `#FFE0B2`, `#FFB74D`

### Customize Partner Section
Each partner card in the HTML:
```html
<div class="partner-card">
    <h3>Nautillus Law</h3>
    <p>Estate planning specialists...</p>
    <span class="feature-tag">Estate Planning</span>
</div>
```

Edit names, descriptions, and badges as needed.

## 🎓 Understanding the Dashboard

### Column 1: Pending Leads (Orange)
- New leads to qualify
- Shows contact type and when received
- "Qualify" button sends form

### Column 2: Sent (Blue)
- Forms sent to clients
- Shows 0% completion
- Can resend if needed

### Column 3: In Progress (Purple)
- Clients actively filling form
- Shows % complete
- Can send reminder if needed

### Column 4: Completed (Teal)
- Clients finished form
- Shows 100% complete
- Ready to submit to Smokeball
- Some already submitted (green)

### Column 5: Overdue (Red)
- Forms past 14 days
- Shows low completion %
- Send reminder to client
- Follow up needed
